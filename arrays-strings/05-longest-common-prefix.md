## Problem: Longest Common Prefix (Easy)

**Link:** https://leetcode.com/problems/longest-common-prefix

### Approach

I compared the characters of the first string with the corresponding characters in the other strings. The comparison stops when a different character is found.

### Complexity

- Time: O(n × m)
- Space: O(1)

### Notes

I tested one group of strings with a common prefix and one group with no common prefix.
