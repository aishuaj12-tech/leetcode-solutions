## Problem: Valid Anagram (Easy)

**Link:** https://leetcode.com/problems/valid-anagram

### Approach

I used a frequency-counting technique to count the occurrence of each character in both strings. If the frequencies are the same, the two strings are anagrams.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

I tested one valid anagram and one case where the string lengths were different.
