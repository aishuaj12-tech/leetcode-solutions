## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string

### Approach

I used the two-pointer technique. One pointer starts from the beginning and the other starts from the end, and the characters are swapped until both pointers meet.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

I tested a normal string and a single-character string locally before submitting.
